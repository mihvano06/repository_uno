# Отчёт по лабораторной работе 1 (Вариант 1)
## Цель
Изучение рекуррентных последовательностей и методов их моделирования с использованием динамического программирования. Реализация алгоритма для вычисления числа кроличьих пар через заданное количество месяцев с учётом параметра плодовитости k.
## Задачи
1.	Создать модель, описывающую рост популяции кроликов по аналогии с последовательностью Фибоначчи, но с модификацией: каждая половозрелая пара производит k пар потомков.
2.	Реализовать алгоритм на Python для вычисления числа пар на n-й месяц.
3.	Проверить корректность работы алгоритма на примерах.
## Инструментарий
•	Язык программирования: Python.
•	Библиотеки: pandas (для создания таблицы с промежуточными результатами).
•	Метод решения: динамическое программирование (итеративное заполнение таблицы состояний).
## Ход работы
1.	Анализ задачи
•	Установлено, что число пар на n-й месяц зависит от количества взрослых и молодых пар в предыдущие месяцы.
•	Взрослые кролики (Reproduction_rabbits) — пары, способные размножаться.
•	Молодые кролики (Young_rabbits) — пары, которые станут взрослыми через месяц.
2.	Реализация алгоритма
Создана функция quan_rab(n, k), которая:
•	Проверяет входные данные на соответствие условиям (n<=40, k<=5).
•	Использует таблицу (DataFrame) для отслеживания состояний популяции по месяцам:
•	Reproduction_rabbits — число взрослых пар.
•	Young_rabbits — число молодых пар.
•	Total_rabbits — общее число пар.
•	Заполняет таблицу по правилам:
•	Взрослые пары текущего месяца = взрослые + молодые пары предыдущего месяца.
•	Молодые пары текущего месяца = k * число взрослых пар предыдущего месяца.
## Выводы
1.	Алгоритм успешно моделирует модифицированную последовательность Фибоначчи с учётом параметра k.
2.	Использование динамического программирования (итеративное заполнение таблицы) позволяет избежать рекурсивных вычислений и повышает эффективность.
3.	Применение библиотеки pandas обеспечивает наглядность промежуточных результатов.
