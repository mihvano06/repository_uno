# Отчёт по лабораторной работе 2 (Вариант 8)
## Цель
Изучение методов поиска открытых рамок считывания (ORF) в ДНК-последовательностях и их трансляции в протеиновые строки. Реализация алгоритма для идентификации всех возможных белковых последовательностей, полученных из шести рамок считывания (прямых и обратных).
## Задачи
1.	Реализовать алгоритм для анализа шести рамок считывания (3 прямых и 3 обратных комплементарных).
2.	Найти все старт-кодоны (ATG → метионин 'M'), стоп-кодоны (TAA, TAG, TGA) и собрать протеиновые последовательности между ними.
3.	Исключить дубликаты белковых строк и вывести уникальные результаты.
## Инструментарий
•	Язык программирования: Python.
•	Библиотеки:
Bio.Seq (Biopython) — для работы с последовательностями, генерации обратного комплемента и трансляции кодонов.
Bio.SeqIO — для чтения FASTA-файлов.
•	Методы:
Построчный анализ трёхнуклеотидных рамок.
Трансляция кодонов в аминокислоты.
## Ход работы
1.	Чтение входных данных
Файл в формате FASTA считывается с помощью Bio.SeqIO, извлекается ДНК-последовательность.
2.	Анализ рамок считывания
•	Для каждой из 6 рамок (3 прямых и 3 обратных) выполняется:
•	Разбиение последовательности на кодоны (триплеты) с шагом 3, начиная с позиций 0, 1, 2.
•	Поиск старт-кодона (M) для начала протеиновой цепочки.
•	Трансляция кодонов до первого стоп-кодона (*).
3.	Сбор результатов
Найденные белковые последовательности сохраняются в множество для исключения дубликатов.
4.	Вывод результатов
Все уникальные протеиновые строки выводятся в произвольном порядке.
## Выводы
1.	Алгоритм успешно идентифицирует все возможные открытые рамки считывания, включая обратную комплементарную цепь ДНК.
2.	Использование множества (set) гарантирует уникальность выводимых протеиновых последовательностей.
3.	Библиотека Biopython значительно упрощает работу с биологическими данными:
•	Генерация обратного комплемента через reverse_complement().
•	Трансляция триплетов в аминокислоты методом translate().
