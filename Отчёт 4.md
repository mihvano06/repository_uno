# Отчёт по лабораторной работе №4
## Цель
Освоение методов работы с биологическими базами данных (NCBI) и инструментами Biopython для обработки геномных данных: формирование файлов GenBank, анализ GC-состава, трансляция кодирующих областей (CDS) в белковые последовательности.
## Задачи
1.	Создать файл GenBank с CDS двух видов растений (Brassica oleracea и Solanum lycopersicum).
2.	Провести анализ GC-состава записей и вывести их в порядке возрастания.
3.	Выполнить трансляцию кодирующих областей в белковые последовательности с указанием их локализации.
## Инструментарий
•	Язык программирования: Python.
•	Библиотеки: Bio.Entrez — доступ к данным NCBI. Bio.SeqIO — чтение и запись файлов GenBank. Bio.SeqUtils.gc_fraction — расчёт GC-состава. Bio.Seq — трансляция нуклеотидных последовательностей.
•	Базы данных: NCBI Nucleotide (для поиска CDS).
## Ход работы
### Задание 1. Формирование исходного файла
1.	Поиск данных в NCBI:
Для каждого вида (Brassica oleracea и Solanum lycopersicum) выполнен запрос complete cds через Entrez.esearch.
Получено по 5 записей (ID) для каждого вида.
2.	Скачивание и объединение:
Для каждого ID через Entrez.efetch загружены данные в формате GenBank.
Все записи объединены в единый файл merged_sequences.gb с помощью SeqIO.write.
### Задание 2. Анализ GC-составов
1.	Чтение файла GenBank:
Записи прочитаны через SeqIO.parse.
2.	Расчёт GC-состава:
Для каждой записи вычислен GC-состав с использованием gc_fraction.
Результаты сохранены в список и отсортированы по возрастанию.
3.	Вывод данных:
Для каждой записи выведены ID, описание и GC-состав (с точностью до 4 знаков).
### Задание 3. Трансляция CDS
1.	Извлечение CDS:
Для каждой записи найдены все признаки типа CDS в файле GenBank.
2.	Трансляция в белки:
Для каждой CDS выполнено извлечение нуклеотидной последовательности (location.extract).
Последовательность транслирована методом translate(to_stop=True) до ближайшего стоп-кодона.
3.	Вывод результатов:
Для каждой CDS указаны: ID записи, локализация (старт, конец, цепь), белковая последовательность.
## Выводы
1.	Формирование файла GenBank:
•	Успешно загружено 10 CDS (по 5 для каждого вида) и сохранено в единый файл.
•	Библиотека Bio.Entrez упрощает доступ к данным NCBI, но требует регистрации email.
2.	GC-составы:
•	Результаты корректно отсортированы, что позволяет сравнивать геномные особенности разных видов.
•	GC-состав варьируется в пределах 35–55%, что типично для растений.
3.	Трансляция CDS:
•	Все кодирующие области успешно транслированы в белки.
•	Метод translate(to_stop=True) гарантирует остановку на первом стоп-кодоне.
