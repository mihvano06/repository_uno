# Отчёт по лабораторной работе 3

## Цель
Освоение методов визуализации данных: построение диаграмм рассеяния и графиков временных рядов для анализа взаимосвязей между переменными и динамики изменения показателей.

## Задачи
Построить диаграмму рассеяния с цветовым разделением данных по классам.

Создать график динамики временного ряда для анализа изменения показателя за определённый период.

Научиться использовать библиотеки matplotlib, seaborn и pandas для визуализации данных.

## Инструментарий
Язык программирования: Python.

Библиотеки:

matplotlib.pyplot — базовый инструмент для построения графиков.

seaborn — расширение для matplotlib с улучшенным дизайном и стилем.

pandas — работа с табличными данными.

sklearn.datasets — загрузка стандартных наборов данных (например, Iris).

statsmodels.datasets — доступ к данным временных рядов (например, расход воды в Ниле).

## Ход работы
### Задание 1. Построение диаграммы рассеяния
Загрузка данных:

Использован встроенный набор данных Iris из sklearn.datasets, содержащий информацию о размерах чашелистиков и лепестков трёх видов ирисов.

Данные преобразованы в DataFrame с добавлением столбца species для обозначения видов.

Визуализация:

С помощью seaborn.scatterplot построена диаграмма рассеяния для двух признаков: длины и ширины чашелистиков.

Параметры:

hue='species' — цвет маркеров зависит от вида ириса.

style='species' — стиль маркеров уникален для каждого вида.

palette='deep' — задана цветовая схема.

Добавлены подписи осей, заголовок и легенда.

### Задание 2. Построение графика динамики временных рядов
Загрузка данных:

Использован набор данных nile из statsmodels.datasets, содержащий информацию о годовом расходе воды в реке Нил за период 1871–1970 гг.

Визуализация:

С помощью matplotlib.pyplot.plot построен график динамики.

Настройки:

Подписи осей: год (ось X) и расход воды (ось Y).

Добавлена сетка (plt.grid(True)) для улучшения читаемости.

Указан заголовок и легенда.

## Выводы
Диаграмма рассеяния:

Позволяет наглядно оценить распределение данных и выявить кластеры. Например, вид setosa имеет меньшую длину чашелистиков, но большую ширину по сравнению с versicolor и virginica.

Использование seaborn упрощает создание сложных визуализаций с автоматическим разделением данных по категориям.

График временных рядов:

Продемонстрировал изменение годового расхода воды в Ниле за 100 лет. На графике видны периоды засух и повышения уровня воды.

matplotlib обеспечивает гибкость в настройке стиля графиков (цвета, сетка, подписи).
